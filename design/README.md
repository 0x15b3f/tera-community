# موقع تيره — حزمة التصميم والهوية البصرية

الحزمة دي فيها كل حاجة اتفقنا عليها قبل بدء التنفيذ: الشعار، الهوية، شاشات الواجهة، والدياجرامز.

## المحتويات

- **01-logo/** — الشعار بصيغة SVG (أساسي) وPNG عالي الجودة بخلفية شفافة: النسخة الأفقية + الأيقونة المربعة.
- **02-brand-guide/** — دليل الهوية البصرية PDF: الألوان بأكوادها، الخطوط، عناصر الواجهة، قواعد استخدام الشعار والصور.
- **03-screens/** — ١٦ لقطة شاشات PNG (موبايل 390px + لوحة الأدمن ديسكتوب):
  1. الرئيسية (بحث + ١٤ تصنيف + عروض + الأقرب ليك + أخبار)
  2. صفحة تصنيف (مطاعم وكافيهات) بفلاتر
  3. حواليك: خريطة بالدبابيس + قائمة الأقرب لموقعك
  4. صفحة المكان (عيادة): مواعيد العمل، الخدمات، اتصال/واتساب/اتجاهات
  5. العروض والإعلانات المميزة
  6. المجتمع: أخبار، مفقودات، وظائف، منشورات فيسبوك
  7. عن تيره: التاريخ والإنجازات والإحصائيات
  8. صفحة الشهداء (المحتوى يُدار من لوحة التحكم)
  9. لوحة تحكم الأدمن (ديسكتوب)
  10. المدرسين والسناتر: فلاتر النوع والمادة والمرحلة ومواعيد الحصص
  11. صفحة المدرس/السنتر: المواد والمراحل، جدول المجموعات، الأسعار
  12. الخدمات الإلكترونية (فوري، محافظ، إنترنت، خدمات حكومية)
  13. محلات الموبايلات (بيع وصيانة واكسسوارات)
  14. العطارة (أعشاب طبية وبهارات وزيوت)
  15. الإعلانات والسوشيال ميديا (إدارة صفحات، إعلانات ممولة، تصميم)
  16. صفحة المحل: نموذج تفاصيل يصلح لأي محل من التصنيفات الجديدة
- **04-diagrams/** — ٣ دياجرامز SVG + PNG: خريطة الصفحات (وفيها فرع التعليم)، رحلة المستخدم (زائر + أدمن)، وERD قاعدة البيانات جاهز لموديلات لارافيل (١٣ جدول، منها tutors ومواد المدرسين ومواعيد المجموعات).
- **05-overview/** — صفحة ملخص واحدة PDF لكل اللي اتعمل.
- **06-source/** — ملفات HTML/CSS المصدر لكل الشاشات والدياجرامز.

## الهوية باختصار

- الألوان: أخضر تيره `#17835B` · كحلي `#0B3B2C` · كهرماني `#F2A93B` · كريمي `#FAF7F0` · أحمر `#D64545`
- الخط: **Cairo** للواجهة كلها، و**Noto Naskh Arabic** للنصوص الطويلة (التاريخ والقصص).
- الشعار: دبوس خريطة جوّاه بيت — «خدمات قريتك جنب بيتك».

## ملاحظات للتنفيذ

- كل البيانات في الشاشات تجريبية (Placeholder) وبتتستبدل من لوحة الأدمن.
- ملف `06-source/mockups/style.css` فيه كل التوكنز (ألوان، بطاقات، أزرار) — يتحول كما هو تقريباً لمشروع Laravel + Livewire، والشاشات تتحول لـ Blade components.
- الـ ERD متصمم على: Model لكل جدول + علاقات hasMany/belongsTo، وFilament يولّد شاشات لوحة الأدمن منها.
- الخريطة في النسخة الحقيقية تبقى Leaflet + OpenStreetMap (مجانية)، والترتيب بالأقرب بمعادلة Haversine على lat/lng.
